# Illustrative individual-level age structure data

Synthetic individual-level records of age class at a reference and a
hunted site, for use with
[`ot_asc()`](https://stangandaho.github.io/offtake/reference/ot_asc.md).
**Simulated, not field data.**

## Usage

``` r
bushmeat_ages
```

## Format

A data frame with 240 rows and 2 variables:

- site_type:

  `"reference"` or `"hunted"`.

- age_class:

  `"juvenile"` or `"adult"`.

## Source

Simulated.
