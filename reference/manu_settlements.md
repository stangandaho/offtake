# Illustrative hunting settlements

Synthetic settlement locations and hunter populations for the spatial
source-sink model
[`ot_biode()`](https://stangandaho.github.io/offtake/reference/ot_biode.md).
Place names are Amazonian but the coordinates and populations are
**simulated and illustrative only.**

## Usage

``` r
manu_settlements
```

## Format

A data frame with 4 rows and 4 variables:

- settlement:

  Settlement name.

- x_km:

  X coordinate (km).

- y_km:

  Y coordinate (km).

- hunters:

  Number of hunters.

## Source

Simulated.
