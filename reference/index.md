# Package index

## Index-based approaches

Compare a harvest or abundance metric between hunted and reference
sites.

- [`ot_asc()`](https://stangandaho.github.io/offtake/reference/ot_asc.md)
  : Age structure comparison (ASC)
- [`ot_hyco()`](https://stangandaho.github.io/offtake/reference/ot_hyco.md)
  : Hunting yield comparison (HYCo)
- [`ot_pdc()`](https://stangandaho.github.io/offtake/reference/ot_pdc.md)
  : Population density comparison (PDC)

## Model-based approaches

Compare observed offtake with an estimated maximum sustainable harvest.

- [`ot_pro()`](https://stangandaho.github.io/offtake/reference/ot_pro.md)
  : Robinson & Redford production model (Pro)
- [`ot_pbr()`](https://stangandaho.github.io/offtake/reference/ot_pbr.md)
  : Potential biological removal (PBR)
- [`ot_msy()`](https://stangandaho.github.io/offtake/reference/ot_msy.md)
  : Maximum sustainable yield of the logistic model (MSY)
- [`ot_samse()`](https://stangandaho.github.io/offtake/reference/ot_samse.md)
  : Sustainable anthropogenic mortality in stochastic environments
  (SAMSE)
- [`ot_biode()`](https://stangandaho.github.io/offtake/reference/ot_biode.md)
  : Biodemographic spatial source-sink model (Biode)
- [`ot_biode_surface()`](https://stangandaho.github.io/offtake/reference/ot_biode_surface.md)
  : Extract the predicted density surface from a Biode result
- [`ot_biode_cpue()`](https://stangandaho.github.io/offtake/reference/ot_biode_cpue.md)
  : Extract per-settlement local CPUE from a Biode result

## Helpers

- [`ot_lambda_max()`](https://stangandaho.github.io/offtake/reference/ot_lambda_max.md)
  : Maximum finite rate of population increase (Cole's equation)

## Datasets

- [`bushmeat_sites`](https://stangandaho.github.io/offtake/reference/bushmeat_sites.md)
  : Illustrative site-level bushmeat survey data
- [`bushmeat_ages`](https://stangandaho.github.io/offtake/reference/bushmeat_ages.md)
  : Illustrative individual-level age structure data
- [`duiker_demography`](https://stangandaho.github.io/offtake/reference/duiker_demography.md)
  : Illustrative duiker demographic parameters
- [`manu_settlements`](https://stangandaho.github.io/offtake/reference/manu_settlements.md)
